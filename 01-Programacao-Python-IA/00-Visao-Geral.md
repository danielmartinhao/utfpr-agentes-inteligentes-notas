# Programação Python para Inteligência Artificial

**Carga horária:** 30h
**Datas das aulas:** 11/09, 12/09, 25/09 e 26/09/2026

## Tópicos a cobrir

**Objetivo:**  

Capacitar o aluno a utilizar a linguagem de programação Python e suas principais bibliotecas como ferramenta fundamental para a  
implementação de algoritmos e modelos de Inteligência Artificial. Ao final da disciplina, o aluno deverá ser proficiente na manipulação de  
dados, visualização e prototipagem de soluções de IA em Python.

**Programa:**  
1) Introdução ao ambiente Python: Instalação de ambientes, IDEs e gerenciamento de pacotes.  
2) Fundamentos da linguagem Python: Tipos de dados, estruturas de controle (condicionais e laços), funções, módulos e tratamento de  
exceções.  
3) Programação Orientada a Objetos em Python: Classes, objetos, herança e polimorfismo aplicados à modelagem de problemas de IA.  
4) NumPy: Manipulação eficiente de arrays e matrizes multidimensionais, operações vetoriais e álgebra linear.  
5) Pandas: Estruturas de dados, leitura e escrita de dados, limpeza, transformação, agregação e junção de dados.  
6) Criação de visualizações de dados.  
7) Apresentação da API unificada para modelos de aprendizado de máquina.
